# Cv To Portfolio Forge

AI Personal Portfolio Website Generator

Act as an expert UI/UX designer, personal branding consultant, and professional web developer.

Analyze the attached CV carefully and automatically generate a complete, modern, professional, and responsive personal portfolio website based entirely on the information provided in the CV.

Requirements:

Automatically extract the person's name, professional title, biography, education, experience, skills, projects, research, publications, achievements, and contact information.

Create personalized website content that accurately represents the individual's professional identity.

Design an elegant, modern, and visually appealing portfolio with a suitable color palette, typography, and layout.

Include relevant sections such as Home, About, Skills, Education, Experience, Projects, Publications, Achievements, and Contact.

Automatically adapt the design and content to the individual's professional background.

Ensure the website is responsive, accessible, SEO-friendly, and optimized for desktop and mobile devices.

Include functional navigation, professional social links, and a CV download button when supported.

Do not invent information, use generic placeholder content, or display empty sections.

Final Instruction:

Do not ask the user for additional information or merely provide a design plan. Use the attached CV as the primary source and immediately build a complete, personalized, ready-to-use portfolio website.

If you are an AI website builder, implement the website directly. If you are a general AI assistant, generate the complete website code with clear instructions for running it.
